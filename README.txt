INSTALLASJON PÅ IPHONE

1. Last opp alle filene i denne mappa til ei HTTPS-nettside.
2. Opne nettadressa i Safari.
3. Trykk Del.
4. Vel «Legg til på Hjem-skjerm».
5. Opne appen frå ikonet.

Appen fungerer offline etter installasjon og lagrar:
- avhukingar
- vekt
- treningsnotat
- handleliste

Data blir lagra lokalt på telefonen.
